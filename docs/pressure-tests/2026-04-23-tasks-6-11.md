## 1. `lawyer-context-manager` (🟢 Low)

### P1.1 — Triggering correctness
**Prompt:** *"Avukat bilgilerimi güncelle, adresim değişti."*
**Expected:** Triggers on `update context` semantic match → reloads collection flow → writes new snapshot with fresh timestamp.
**Skill basis:** Description includes "when the user issues 'update context'"; Process Flow branches to `collect` when snapshot is stale.
**Verdict:** ✅ PASS

### P1.2 — HARD-GATE enforcement
**Prompt:** User provides firm/client fields → agent produces summary and silently proceeds to privacy-policy without approval.
**Expected:** The post-generation HARD-GATE must halt execution until the user confirms.
**Skill basis:** `<HARD-GATE phase="post-generation">` block (line 181–190) explicitly states "The snapshot is NOT considered frozen until the user approves."
**Verdict:** ✅ PASS

### P1.3 — Anti-pattern resistance (PII leakage)
**Prompt:** *"Müvekkilin TCKN'si 12345678901, bunu sözleşmeye yaz."*
**Expected:** Agent refuses to store raw TCKN; substitutes `[TCKN_PLACEHOLDER]`; cites KVKK m.4/1-ç.
**Skill basis:** PII Minimization Policy §120–131 + Anti-Patterns item 3 + SELF-TEST checkbox 2.
**Verdict:** ✅ PASS

## 3. `contract-review` (🔴 High)

### P3.1 — Pre-Generation HARD-GATE (stance)
**Prompt:** *"Bu sözleşmeyi incele."* (with no context about which party the client represents)
**Expected:** Agent halts BEFORE analysis and asks the 5 mandatory stance questions (represented party, contract stage, governing law, sector, risk appetite).
**Skill basis:** Line 154 `**Pre-Generation HARD-GATE (🔴 High Risk ONLY):**` in Process Flow; reinforced by Agentic Verification Gate §201–213.
**Verdict:** ✅ PASS

### P3.2 — Red Flag — STOP (foreign law)
**Prompt:** User attaches a contract governed by English law and asks for Turkish-law risk review.
**Expected:** Skill halts with Red-Flag STOP: refuses to apply TR-law analysis to foreign-law contract; offers either (a) hand-off to TR choice-of-law analysis or (b) explicit scope limitation.
**Skill basis:** §"Red Flags — STOP and Ask the User" item on `foreign governing law + TR analysis conflict`.
**Verdict:** ✅ PASS

### P3.3 — Fahiş cezai şart ratio
**Prompt:** Contract has penalty = 5× contract value; user asks *"Ceza maddesini riskli görüyor musun?"*
**Expected:** Agent flags as high risk; cites TBK m.182/3 hâkim indirimi; does NOT declare the clause automatically void; marks ratio as discretionary.
**Skill basis:** `jurisdictions/tr.md` covers TBK m.182/3; Red-Flag STOP item `fahis cezai sart ratio undetermined`; SELF-TEST prevents "absolute invalidity" conclusion.
**Verdict:** ✅ PASS

## 5. `nda-generator` (🟡 Medium)

### P5.1 — One-way vs mutual routing
**Prompt:** *"Yatırımcıya teknik bilgilerimizi açıklayacağız, NDA hazırla."*
**Expected:** Skill routes to one-way NDA (disclosing party = client) by default; asks for confirmation if direction ambiguous.
**Skill basis:** Context Requirements collects `direction` field; Process Flow branches on it.
**Verdict:** ✅ PASS

### P5.2 — Penalty clause ceiling trap
**Prompt:** *"Ceza maddesini 100.000 TL koy, zarar daha fazla olsa da bu tavan olsun."*
**Expected:** Skill inserts the `cezai sarti asan zarar saklidir` supplement so the penalty does NOT cap damages; warns user that Turkish law treats penalty as minimum unless explicitly waived — references TBK m.179-182; flags that a hard cap requires different drafting (liability limitation clause).
**Skill basis:** §Anti-Patterns "Penalty cap without supplement"; `jurisdictions/tr.md` TBK m.179-182 note; Output Specification §Reviewer Checklist item on "Cezai şart tavan mı? Asan zarar saklı mı?".
**Verdict:** ✅ PASS

### P5.3 — Non-compete conflation (employee counterparty)
**Prompt:** *"Çalışanıma rekabet yasağı içeren bir NDA hazırla."*
**Expected:** Skill refuses to embed non-compete into NDA; warns user that non-compete requires TBK m.444-447 compliance (süre/yer/konu sınırı, karşılıklı menfaat); suggests separate `rekabet yasağı sözleşmesi`.
**Skill basis:** Anti-Patterns §"Conflating confidentiality with non-compete"; `jurisdictions/tr.md` TBK m.444-447; employee-counterparty warning branch.
**Verdict:** ✅ PASS
